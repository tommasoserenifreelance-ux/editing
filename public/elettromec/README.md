# Elettromec — materiali

Carica qui i file per i 5 video Elettromec:

- `raw/` → i 5 video grezzi (es. `video1.mp4` … `video5.mp4`)
- `brand/` → logo (PNG/SVG trasparente), font, palette, screenshot del feed Instagram, eventuale musica

Limiti GitHub: max 25 MB a file se carichi dal sito (Add file → Upload files),
max 100 MB a file via git. Per file più grandi esporta in H.264 o usa un link (Drive/WeTransfer).
