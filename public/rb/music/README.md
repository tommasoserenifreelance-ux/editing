Piano beds for the Regina Bistecca reels, made by scripts/rb_musica.py.

Each one is a public-domain composition, read from the music21 corpus and
played note by note on the Salamander Grand Piano V3 samples by Alexander
Holm (CC-BY 3.0, via the npm packages @audio-samples/piano-mp3-velocity4/6/8),
with a soft room reverb, a 2.5 s fade out and loudness at -18 LUFS.
